# KATADRAW ステージセレクト 新仕様（変更仕様書）

**対象ファイル**: `scenes/stage_select.gd` / `scripts/StageSelectManager.gd`  
**この文書の目的**: 現行仕様からの変更点を定義し、Claude Code への実装指示のベースとして使う  
**現行仕様との対照**: `ステージセレクト仕様.md`（現行仕様書）を併読すること

---

## 0. 変更の概要

現行の「5×10碁盤目グリッド」を廃止し、**ハニカム構造（正三角形・逆正三角形の連続）** による左→右方向展開のステージマップに全面変更する。  
カメラはズームイン状態で一部のみを表示し、プレイヤーアバターの移動に追従してスクロールする。

## 1. ステージ構成

### ステージ数・ID

- 総ステージ数: **50**（ID: 0〜49）
- **ステージ50（エクストラ）**: ID 0〜49 を全クリア後に特別演出を経てプレイ可能。位置・実装は現時点では対象外とし、後日定義する。
- 現行の `stage_id: 0, 1, 2` は新仕様の `id: 0, 1, 2` に対応する。

### スタートステージ

- `id: 0` のみ初期 UNLOCKED、他は LOCKED。

## 2. レイアウト構造

### 基本方針

- **ハニカム格子**（正三角形と逆正三角形が連続する構造）で全ノードを配置する。
- 接続ラインの角度は常に **±30度または垂直**（正三角形の辺に沿う）。
- 進行方向は **左→右・下→上** が大まかな流れだが、プレイヤーは任意の方向へ移動可能。

### 座標計算式

各ノードは `[col, row]` の格子座標を持つ（画像の格子表に準拠）。

```
X = col * X_PITCH
Y = row * X_PITCH * √3
```

- `X_PITCH` は実装時に調整する定数（画面サイズとズーム倍率に応じて決定）
- Y方向のオフセットは不要（rowの奇偶がすでに半ピッチのずれを表現している）

## 3. 接続・解放ロジック

### 接続リスト（全ノード）

「接続」は **隣接する全ノード** を双方向で定義する。

### 一本道ゾーン（ID 0〜3）

- 0→1→2→3 は **この順にしかプレイできない一本道**。
- 0クリアで1のみ解放、1クリアで2のみ解放、2クリアで3のみ解放。
- 3クリアで4と5が解放され、以降は上記の接続リストに従う通常ロジックに合流する。

## 4. 画面表示・カメラ

### ワールドサイズ

ノード座標はワールド座標系で管理する。一度に画面に表示されるのは **概ね3列×5行分** のノード（厳密な値ではなく目安）。

### ズーム

ステージマップにズームインした状態で表示し、全体マップを一画面には収めない。  
ズーム倍率は実装時に調整する（目安：現行比4倍程度）。

### カメラ追従（通常時）

- プレイヤーアバターが **画面端から20%以内の領域**に入ったら、その方向へスクロールを開始する。
- 画面中央付近でアバターを動かしている間はスクロールしない。

### カメラ演出（ステージ解放時）

ステージクリア直後、新たに解放されたノードを **接続リストの順に1つずつカメラがフォーカス** する。  
全ノードを巡り終わったら、自動でプレイヤーアバターの位置にカメラが戻る。

## 5. BGM解禁ゾーン

マップ上に **4つの水色ゾーン** が存在し、それぞれを囲むノードを全てクリアすることで BGM が1曲ずつ解禁される。

- **初期解禁BGM**: 1曲
- **最大BGM数**: 5曲（初期1曲 ＋ ゾーン解禁4曲）

### ゾーン定義

| ゾーン | 必要クリアステージ | 解禁BGM |
|--------|-------------------|---------|
| ゾーン1（左上） | 8, 9, 13, 14, 17, 18 | 未定 |
| ゾーン2（左下） | 11, 12, 15, 16, 21, 22 | 未定 |
| ゾーン3（中央） | 27, 28, 31, 32, 35, 36 | 未定 |
| ゾーン4（右下） | 39, 40, 43, 44, 47, 48 | 未定 |

解禁されるBGMの曲名は後日 `manifest.json` で定義する。
