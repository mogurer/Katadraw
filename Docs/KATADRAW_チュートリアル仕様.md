# KATADRAW チュートリアル仕様

**対象ファイル**: `scripts/game.gd`、`scripts/StageSelectManager.gd`

---

## 概要

KATADRAW のチュートリアルはゲームのルール説明画面（`rules` フェーズ）として実装されている。  
初回プレイ時に自動表示され、コンフィグ画面からも再表示できる。

---

## チュートリアルフラグ

| フラグ | 型 | 保存 | 説明 |
|--------|-----|------|------|
| `tutorial_shown` | bool | ◎ | チュートリアルを1度でも表示したことがある |
| `tutorial_return_to` | String | ✕ | チュートリアル完了後の戻り先（セッションのみ） |

---

## 表示フロー

### 初回プレイ時（自動表示）

```
タイトル → メニュー → [スタート]
  └─（tutorial_shown == false）
        └─ tutorial_shown = true を保存
           tutorial_return_to = "stage1"
           game_state = "rules"（チュートリアル表示）
                └─ [つぎへ] → ステージセレクトシーンへ遷移
```

### コンフィグからの再表示

```
コンフィグ → [チュートリアルを見る]
  └─ tutorial_return_to = "config"
     game_state = "rules"（チュートリアル表示）
          └─ [つぎへ] → コンフィグ画面へ戻る
          └─ [ESC / B ボタン] → コンフィグ画面へ戻る
```

---

## 操作

| 操作 | KBM | コントローラ | 動作 |
|------|-----|------------|------|
| 次のページ / 閉じる | 左クリック / Enter | A ボタン / Start | 「つぎへ」ボタン押下 |
| キャンセル | ESC | B ボタン | 戻り先へ戻る |

---

## 戻り先の決定

`tutorial_return_to` の値によって遷移先が変わる。

| `tutorial_return_to` | つぎへ時の遷移 | ESC/B 時の遷移 |
|---------------------|--------------|--------------|
| `"stage1"` | ステージセレクトシーンへ | メニューへ |
| `"config"` | コンフィグ画面へ | コンフィグ画面へ |
| `""` | ステージセレクトシーンへ | メニューへ |

遷移後、`tutorial_return_to` は `""` にリセットされる。

---

## rules フェーズの UI

- ルール説明テキストおよびイラストを複数ページで表示
- 「つぎへ」ボタンが画面内に配置される
- コントローラモードでは自キャラが「つぎへ」ボタン位置に初期配置される
