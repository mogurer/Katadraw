# KATADRAW 操作仕様

---

## 画面別操作一覧

### タイトル / メニュー

| 操作 | KBM | コントローラ |
|------|-----|------------|
| 項目選択・決定 | マウス左クリック | A ボタン |
| キャンセル・戻る | ESC | B ボタン |

---

### コンフィグ

| 操作 | KBM | コントローラ |
|------|-----|------------|
| 項目変更（左） | 左クリック（◀） | ← / L ボタン |
| 項目変更（右） | 左クリック（▶） | → / R ボタン |
| 戻る | ESC | B ボタン |
| チュートリアルを見る | クリック | A ボタン |

---

### チュートリアル（rules 画面）

| 操作 | KBM | コントローラ |
|------|-----|------------|
| 次のページへ / 閉じる | マウス左クリック / Enter | A ボタン / Start |
| 戻る（コンフィグ経由時） | ESC | B ボタン |

---

### ステージセレクト

| 操作 | KBM | コントローラ |
|------|-----|------------|
| キャラ移動 | マウス追従 | 左スティック（600px/s） |
| ステージ近傍移動 | — | 右スティックスナップ（閾値 80%） |
| ステージ選択 | 左クリック（ホバー時） | A ボタン（最近傍） |
| ポップアップ：はい | 左クリック / Enter | A ボタン |
| ポップアップ：いいえ | ESC | B ボタン |
| タイトルへ戻る（ポップアップ） | ESC | Start |
| BGM 前へ | Q | L ボタン |
| BGM 次へ | E | R ボタン |
| BGM 拡大表示 | 右クリック保持 | X ボタン保持 |

---

### インゲーム（playing フェーズ）

#### マウス操作

| 操作 | 動作 |
|------|------|
| マウス移動 | 自キャラ追従（lerp 係数 10.0） |
| 左ボタン押下 | 斥力（キャラ周辺のポイントを弾く） |
| 右ボタン押下 | 引力（キャラ周辺のポイントを引き寄せる） |
| 左右同時押し | ネコアニメーション（特殊演出） |
| ポイント付近で左クリック→ドラッグ | ポイントをつかんで移動 |
| 矩形ドラッグ（空白エリア） | 複数ポイントを範囲選択 |
| Shift + ドラッグ | 移動量を 1/3 に精密モード |

#### コントローラ操作

| 操作 | 動作 |
|------|------|
| 左スティック | 自キャラ移動（加速あり、最高 5120px/s） |
| D-Pad | 自キャラ移動（補助） |
| A ボタン押下 | 斥力 |
| X ボタン押下 | 引力 |
| A + X 同時押し | ネコアニメーション（特殊演出） |
| B ボタン | 斥力・引力を解除 |
| 右スティック（傾け） | 最近傍ポイントを選択・ドラッグ移動 |
| L / R ボタン | 選択ポイントを多角形に沿って前後に循環 |

#### 右スティック詳細

| 動作 | 説明 |
|------|------|
| スティック傾け | 自キャラ位置から射線を発射し、射線沿いの最近傍ポイントを選択 |
| スティック維持 + L/R | 射線バンドル内で選択を循環 |
| デッドゾーン | 80%（= 0.8） |
| 再検出角度 | 5° 以上の方向変化で新しい射線を再計算 |
| ショルダーレイ半角 | 22°（バンドル幅） |

## 入力モード自動切替（ステージセレクト）

| イベント | モード切替 |
|---------|-----------|
| マウスボタン押下 | KBM モード |
| キーボードキー押下 | KBM モード |
| コントローラボタン押下 | コントローラモード |

切替によってステージセレクト左下ガイドと BGM ボタンラベルが即座に更新される。

## インゲーム物理パラメータ（参考）

| 定数 | 値 | 説明 |
|------|-----|------|
| `PLAYER_ACCEL` | 2560 px/s² | パッド移動加速度 |
| `PLAYER_SPEED_SOFT_CAP` | 500 px/s | 通常速度上限 |
| `PLAYER_SPEED_HARD_CAP` | 5120 px/s | 絶対速度上限 |
| `PLAYER_MOVE_RAMP_TIME_MS` | 960 ms | 加速ランプアップ時間 |
| `HOVER_DISTANCE` | 30 px | ポイントホバー判定距離 |
| `CLICK_HIT_DISTANCE` | 30 px | ポイントクリック判定距離 |
| `PAD_CURSOR_SPEED` | 600 px/s | パッドカーソル速度 |
