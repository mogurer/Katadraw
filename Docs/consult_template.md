# 相談テンプレート (Claude Codeに投げる前の要件整理用)

このリポジトリでの開発は「Claude(チャット)で要件を整理 → Claude Code用の指示書を生成 → Claude Codeで実装 → 課題があればまたClaudeで相談」という流れで進めています。
相談を始めるとき、以下の項目を埋められる範囲で埋めてから話し始めると、要件がスムーズに固まります。全部埋まっていなくてOK、わからない項目は「不明」「Claudeに調査してほしい」と書けば大丈夫です。

## 相談後の流れ(参考)

1. 上記をベースにClaudeと相談し、要件と根本原因を言語化する
2. Claudeが「検証してから修正する」形式のClaude Code向け指示書(日本語)を生成する
3. Claude Codeで実装・検証
4. 結果をClaudeに報告し、問題があれば再度相談
5. 大きめの設計判断が生まれた場合は `Docs/DECISIONS.md` に追記する
