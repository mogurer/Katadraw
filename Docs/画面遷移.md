# KATA-DRAW 画面遷移

タイトル画面からインゲーム、リザルト、タイトルに戻るまでの画面遷移を整理する。

---

## 1. 状態一覧（game_state）

| 状態 | 説明 |
|------|------|
| `logo` | ロゴ表示（起動直後） |
| `title` | タイトル画面 |
| `menu` | メインメニュー（ゲーム開始 / 設定） |
| `config` | 設定画面（解像度・ウィンドウモード・言語） |
| `rules` | ルール説明 |
| `guide_info` | ステージ開始前のガイド（図形タイプ説明） |
| `guide_countdown` | カウントダウン（3→2→1） |
| `playing` | プレイ中 |
| `cleared` | ステージクリア（パーティクル表示） |
| `results` | リザルト（全ステージクリア後） |

※ `pause_active` が true のときは `playing` の上にポーズオーバーレイを表示

---

## 3. 遷移の詳細

### 3.1 タイトル周辺

| 遷移元 | 遷移先 | トリガー |
|--------|--------|----------|
| logo | title | クリック / Enter / A |
| title | menu | クリック / Enter / A |
| results | title | クリック / Enter / A |

### 3.2 メニュー・設定

| 遷移元 | 遷移先 | トリガー |
|--------|--------|----------|
| menu | title | ESC / B |
| menu | rules | Game Start（menu_index=0） |
| menu | config | Config（menu_index=1） |
| config | menu | ESC / B / 戻る選択 |
| rules | guide_info | [次へ]ボタンクリック（マウス）/ Start / Enter / Space（パッド）でゲーム開始。この選択によりプレイ中の入力がロック（マウス or パッドのみ） |

### 3.3 ゲームフロー

| 遷移元 | 遷移先 | トリガー |
|--------|--------|----------|
| guide_info | guide_countdown | クリック / Enter / A |
| guide_countdown | playing | 3秒経過（_process で自動） |
| playing | cleared | クリア判定（_check_clear） |
| cleared | guide_info | 次のステージあり（_advance_stage → _start_stage） |
| cleared | results | 全ステージクリア（_advance_stage） |
| results | title | クリック / Enter / A |

### 3.4 ポーズ（playing の上にオーバーレイ）

| 操作 | 動作 |
|------|------|
| ESC / Start | pause_active = true |
| 続ける | pause_active = false（タイマー復帰） |
| 操作説明 | pause_show_controls = true |
| タイトルへ | pause_confirm_title = true → Yes で title |

---

## 4. 主要関数と役割

| 関数 | 役割 |
|------|------|
| `_start_game()` | BGM停止、stage_times クリア、_start_stage(0) |
| `_start_stage(idx)` | ステージ生成、guide_info へ |
| `_advance_stage()` | 次ステージ or results へ |
| `_check_clear()` | クリア判定、cleared へ遷移、stage_times.append |

---

## 5. BGM の切り替えタイミング

| 遷移 | BGM |
|------|-----|
| logo → title | bgm_title |
| rules → guide_info | bgm_title 停止 |
| guide_countdown → playing | bgm_game |
| cleared → results | bgm_game 停止、bgm_result |
| results → title | bgm_result 停止、bgm_title |
| ポーズ「タイトルへ」Yes | bgm_game 停止、bgm_title |

## 6. トランジション・アニメーション演出

### 6.1 TransitionManager ワイプ（`scripts/TransitionManager.gd`）

シーン間またはゲームステート間の切り替えに挟むワイプアニメーション。
詳細なメソッドシグネチャ・定数は `Docs/KATADRAW_現行仕様.md` セクション 2.7 を参照。

#### タイミング共通（全パターン）

```
[COVER 0.32s] → [HOLD 0.05s] → [REVEAL 0.32s]   合計 0.69s
                      ↑
               on_mid コールバック実行
          （シーン遷移 / ゲームステート変更はここで行う）
```

#### パターン別 トリガー対応表

| ユーザー操作 / 状況 | パターン | 呼び出し元 |
|---------------------|---------|-----------|
| ステージセレクト：ステージ確認 [はい] → ゲーム開始 | 三角ワイプ | `stage_select.gd` |
| ステージセレクト：[DEBUG] ゾウステージ直接起動 | 三角ワイプ | `stage_select.gd` |
| ゲーム中ポーズ：[ステージをやめる] | 三角ワイプ | `game.gd` |
| ゲーム中：ステージクリア後の自動進行（SE なし） | 三角ワイプ | `game.gd` |
| ゲーム中：F2 デバッグ終了 → ステージセレクトへ | 三角ワイプ | `game.gd` |
| ステージセレクト：ESC 確認 [はい]（タイトルへ） | 六角ワイプ | `stage_select.gd` |
| メニュー：「設定」選択 | 対角ワイプ | `game.gd` |
| 設定：「クレジット」選択 | 対角ワイプ | `game.gd` |
| 設定：[戻る] 選択 | 対角ワイプ | `game.gd` |
| クレジット：ESC / B ボタンで設定へ戻る | 対角ワイプ | `game.gd` |
| メニュー：「ゲーム開始」（2 回目以降）→ ステージセレクトへ | 対角ワイプ | `game.gd` |

> **備考（六角ワイプの遷移先）**：ステージセレクト ESC 確認 [はい] は `game.tscn` へのシーン切り替えだが、
> `pending_stage_id` が未設定のため `game.tscn` は `logo` state から起動する（事実上タイトルへ戻る全再起動）。

### 6.2 その他の画面演出（TransitionManager 非使用）

#### ロゴ演出（`logo` ステート）

| フェーズ | 定数 | 時間 |
|---------|------|------|
| 表示前待機 | `LOGO_WAIT1` | 1.0 秒 |
| フェードイン | `LOGO_FADE_IN` | 1.0 秒 |
| 表示保持 | `LOGO_HOLD` | 2.0 秒 |
| フェードアウト | `LOGO_FADE_OUT` | 1.0 秒 |
| 表示後待機 | `LOGO_WAIT2` | 1.0 秒 |
| 合計 | `LOGO_TOTAL` | **7.0 秒**（任意キーでスキップ可） |

#### タイトルフェードイン（`title` ステート）

`title_intro` 完了後、タイトル要素が `TITLE_FADE_IN = 0.5` 秒でフェードイン。

#### K 字イントロアニメーション（`title_intro` ステート）

全長 **10.1 秒**（`TI_TOTAL_DUR`）の K 字モーフアニメーション。
任意キーでスキップすると `TITLE_INTRO_SKIP_FADE = 1.0` 秒フェードで `title` へ移行。

#### ステージイントロ（`playing` ステート開始直後）

`playing` 開始から **0.5 秒**（`STAGE_INTRO_DURATION`）は入力不可期間。
SE: `katadraw_stagestart.wav` が再生される。

#### クリア演出（`cleared` ステート）

`CLEAR_ANIM_TIME` 定数で管理する CPUParticles2D パーティクル演出。
SE: `se_stageclear.wav` / `se_stageclear02.wav`。

#### リザルト スライドイン（`results` ステート）

全ステージクリア後のスコア行が **0.7 秒**（`RESULTS_SLIDE_DURATION`）でスライドイン表示。
