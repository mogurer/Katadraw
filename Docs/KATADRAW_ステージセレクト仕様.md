# KATADRAW ステージセレクト仕様

**対象ファイル**: `scenes/stage_select.gd` / `scripts/StageSelectManager.gd`

---

## グリッドレイアウト

### 座標計算

ステージはハニカム（六角形）グリッド上に配置される。

```
x = col × X_PITCH × SQRT3
y = row × X_PITCH + y_offset
```

| 定数 | 値 | 説明 |
|------|-----|------|
| `X_PITCH` | 200.0 | グリッドの基本ピッチ（px） |
| `SQRT3` | 1.7320508 | √3（六角グリッド変換係数） |

`y_offset` は各ステージ個別の垂直オフセット（`manifest.json` で指定）。  
ステージ配置の真データは `data/manifest.json` および `data/stage_select_manifest.json` を参照。

### ステージ数

- 通常ステージ：0〜49（計50ステージ）
- 最終ステージ：Zou（グリッド位置 [1, 8]、`zou_cleared` フラグが true のとき表示）

### 一本道ゾーン（最初の4ステージ）

ステージ 0→1→2→3 は接続リストではなく専用の線形ルートで解放される。

```gdscript
_LINEAR_ZONE = { 0: [1], 1: [2], 2: [3] }
```

| 定数 | 値 | 説明 |
|------|-----|------|
| `_BG_COLOR` | `Color(1.0, 0.937, 0.89)` | 背景（クリームピンク） |
| `_LINE_COLOR` | `#433647` | 接続ライン・KATA 線の色 |

| `_CLEARED_COLOR` | `Color(0.95, 0.19, 0.32, 0.55)` | クリア済みドット（薄赤） |
| `_HOVER_COLOR` | `Color(1.0, 0.10, 0.20)` | ホバー時ドット（明赤） |
| `_CHAR_COLOR` | `Color(0.26, 0.21, 0.28)` → `#433647`（インク色統一後） | キャラクターの色 |
| `_BGM_ZONE_COLOR` | `#4477CC` | BGM 解禁ゾーンの青点・青線 |

## ステージドット

| 状態 | 表示 | 内側白丸 |
|------|------|---------|
| LOCKED | 非表示 | — |
| UNLOCKED | `_UNLOCKED_COLOR`（赤） | なし |
| CLEARED | `_CLEARED_COLOR`（薄赤） | あり（半径 × 0.35） |
| HOVER | `_HOVER_COLOR`（明赤） | CLEARED に準じる |

- 通常ドット半径：`_DOT_RADIUS` = 20px
- HOVER 時：1.5 倍に拡大
- ぼよよんアニメーション（解放演出時）：0.5 秒で 1.0→1.6→0.8→1.2→1.0 倍

### ぷるぷるアニメーション

全ドットが起動時にランダム周波数・位相・振幅で Y 方向に浮遊する。

| パラメータ | 範囲 |
|-----------|------|
| 周波数 | 0.5〜1.2 rad/s |
| 位相 | 0〜2π rad |
| 振幅 | 4〜9 px |

### Zou ドット

- 表示条件：`zou_cleared == true` かつ最終演出終了後
- 半径：`_DOT_RADIUS × 2.0`（40px）
- 色：通常時 `Color(0.26, 0.21, 0.28)` → `#433647`（インク色統一後）/ ホバー時 `_HOVER_COLOR`（明赤）
- 内側白丸あり（半径 × 0.35）

---

## 接続ライン

- 表示条件：両端ステージが LOCKED でないこと
- 色：`_LINE_COLOR`（`#433647`）
- 太さ：`_LINE_WIDTH` = 4px
- 解放演出時：解放元から新ドットへ `UNLOCK_LINE_FADE_DURATION`（2.5s）かけて描線アニメーション

## BGM 解禁ゾーン（青い点・線）

4ヶ所の青点が常時表示される。周囲6ステージをすべてクリアするとゾーンが完成し BGM が1つ解放される。

| ゾーン | 必要ステージ | グリッド中心 | 解放 BGM |
|--------|------------|------------|---------|
| 1 | 8, 9, 13, 14, 17, 18 | [3, 4] | 01-06 |
| 2 | 11, 12, 15, 16, 21, 22 | [4, 9] | 01-08 |
| 3 | 27, 28, 31, 32, 35, 36 | [7, 6] | 02-03 |
| 4 | 39, 40, 43, 44, 47, 48 | [10, 9] | 02-09 |

| 要素 | 仕様 |
|------|------|
| 青点の色 | `_BGM_ZONE_COLOR`（`#4477CC`） |
| 青点の半径 | `_DOT_RADIUS × 1.5`（30px） |
| 青い線 | CLEARED ステージ → 青点中心、同色・同太さ |

## ステージ解放フォーカス演出

ステージクリア後にステージセレクトへ戻ったとき、新たに解放されたステージへカメラが順番に移動する。

| パラメータ | 値 |
|-----------|-----|
| カメラ移動速度 | `FOCUS_MOVE_SPEED` = 1200px/s（リニア） |
| ぼよよんアニメーション | `UNLOCK_ANIM_DURATION` = 0.5s |
| 接続ライン出現時間 | `UNLOCK_LINE_FADE_DURATION` = 2.5s |

演出終了後：カメラをクリアしたステージへ戻す。次に BGM 解禁演出が待機中なら続けて開始する。

---

## BGM 解禁演出シーケンス

ゾーン完成を `_ready()` で検出後、ステージ解放フォーカス演出の終了後に開始する。  
（フォーカス演出がない場合は即時開始。）

| ステップ | 内容 | 時間 |
|---------|------|------|
| 1 | カメラが青点位置へスライド | 0.5s（EASE_OUT QUAD） |
| 2 | パーティクル発生（180粒子・`#4477CC`） + BGM 拡大 UI 展開 | 即時 + 0.15s |
| 3 | BGM を新トラックへ切り替え・UI ラベル更新 | 即時 |
| 4 | 待機 | 0.5s |
| 5 | BGM 拡大 UI を右下へ収納 | 0.15s |

### スキップ

演出中に以下を合計2回入力するとスキップ（即終了・カメラ青点位置・BGM 切替済み・UI 非表示）。

- マウス左クリック / 右クリック / コントローラ A / X ボタン

## 最終演出（all_cleared トリガー）

通常ステージ（0〜49）をすべてクリアすると、ステージセレクトへ戻った際に1度だけ実行される。  
`zou_cleared == true` の場合はスキップ。

| フェーズ | 内容 |
|---------|------|
| Phase 1 | 画面が徐々に暗転 |
| Phase 2 | 赤いスパーク光がステージ間の辺を伝播 |
| Phase 3 | 全辺収束後、中央でモーフィングアニメーション（縮小） |
| Phase 3（TAP-TO-START） | 「THANK YOU FOR PLAYING!」 → 任意入力で Zou ステージへ遷移 |

演出中 BGM：`BGMManager.stop()` → `TransitionManager.play_triangle()` SE のみ。

## 描画順序

1. 背景（クリームピンク）
2. STAGE / SELECT ロゴ（背景固定・透明度 20%）
3. 接続ライン（白線）
4. BGM 解禁ゾーン：青い線（CLEARED ステージ → 青点）
5. BGM 解禁ゾーン：青点（常時）
6. ステージドット（ぷるぷる + ぼよよん）
7. Zou ドット（`zou_cleared` 時）
8. 自キャラ（通常時・ポップアップ非表示）
9. 吹き出し
10. 装飾トライアングル（左下）
11. ガイドテキスト（左下）
12. 確認ポップアップ / ESC ポップアップ
13. 最終演出オーバーレイ（暗転・スパーク・モーフ・Phase3 テキスト）
14. 自キャラ（ポップアップ表示時・最前面）

## デバッグ機能（`OS.is_debug_build()` 時のみ）

- SE 選択パネル：Ctrl 押下中に画面上部に表示。クリックで SE を試聴再生。
- Zou ドット：デバッグモードでは `zou_cleared` に関係なく常時表示。
