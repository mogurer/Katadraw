# KATADRAW 概要

---

## ゲームコンセプト

**KATADRAW** は、画面に表示されたガイド図形（KATA）に自分のKATAを重ね合わせてクリアを目指すパズルゲームである。  
プレイヤーはポイントを動かしてKATAの形を整え、ガイドとの一致率が基準値を超えると自動的にクリアとなる。

---

## 画面一覧

| 画面 | game_state 値 | 説明 |
|------|--------------|------|
| ロゴ | `logo` | 起動直後のロゴ表示 |
| タイトルイントロ | `title_intro` | タイトルへの遷移アニメーション |
| タイトル | `title` | タイトル画面・BGM再生中 |
| メニュー | `menu` | スタート・コンフィグ・クレジット選択 |
| コンフィグ | `config` | 音量・マウス設定 |
| クレジット | `credit` | クレジット表示 |
| チュートリアル（ルール説明） | `rules` | 初回プレイ時に表示されるルール画面 |
| ガイド情報 | `guide_info` | ステージ開始前のKATA名表示・タイプライター演出 |
| ガイドカウントダウン | `guide_countdown` | 3秒カウントダウン（BGM音量低下） |
| プレイ中 | `playing` | KATA描画・一致率リアルタイム表示 |
| クリア | `cleared` | クリア演出・タイム・ムーブ数表示 |
| リザルト | `results` | ステージ群のクリア結果一覧 |
| Zou エンディング | `zou_ending` | 最終ステージクリア後のスタッフロール |
| ステージセレクト | —（別シーン） | ステージ選択・ワールドマップ |

---

## 画面遷移フロー

```
起動
  └─ logo
       └─ title_intro
            └─ title
                 └─ menu
                       ├─ config ──────────────────────→ menu
                       ├─ credit ──────────────────────→ menu
                       └─ [スタート]
                             ├─（初回）→ rules → ステージセレクトシーン
                             └─（2回目以降）→ ステージセレクトシーン

ステージセレクトシーン
  └─ ステージ選択 → game シーン（guide_info）
                        └─ guide_countdown
                              └─ playing
                                    └─ cleared
                                          ├─ [次のステージ] → guide_info（次ステージ）
                                          └─ [終了・戻る] → ステージセレクトシーン
                                                                または title

最終ステージ（Zou）クリア
  └─ zou_ending → zou_transition → title（または ステージセレクト）
```
