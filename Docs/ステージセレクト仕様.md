## 1. 画面レイアウト

### 基本

| 項目 | 値 |
|------|----|
| 背景色 | `Color(1.0, 0.937, 0.89)` — クリームピンク |
| 接続ライン色 | `Color(0.80, 0.70, 0.67)` |
| 接続ライン幅 | 2.0 px |

### グリッド構成

- **10 列 × 5 行 = 50 スロット**
- X 範囲: 200〜1720 px（列間隔 ≈ 169 px）
- Y 範囲: 250〜830 px（行間隔 = 145 px）

### ステージドット

| 状態 | 色 | 備考 |
|------|----|------|
| LOCKED | `Color(0.72, 0.62, 0.60)` | |
| UNLOCKED | `Color(0.95, 0.19, 0.32)` — 赤 | |
| CLEARED | `Color(0.95, 0.19, 0.32, 0.55)` — 赤 50% | 中央に白円（半径 7.0 px） |
| HOVER（最近傍） | `Color(1.0, 0.10, 0.20)` — 濃赤 | |

- 半径: **20.0 px**

### ドットのぷるぷるアニメーション

起動時にステージごとランダムに初期化。毎フレーム `elapsed` を加算してサイン波で Y 方向にオフセット。

| パラメータ | 範囲 |
|-----------|------|
| 周波数 `_anim_freq[i]` | `randf_range(0.5, 1.2)` rad/s |
| 位相 `_anim_phase[i]` | `randf_range(0.0, TAU)` rad |
| 振幅 `_anim_amp[i]` | `randf_range(4.0, 9.0)` px |

```
dot_y = base_y + sin(elapsed × freq + phase) × amp
```

### 「STAGE / SELECT」ロゴ

- フォント: D-DIN-PRO-700-Bold.otf（字間 −4 px）
- サイズ: 400
- 色: `Color(0.26, 0.21, 0.28, 0.2)` — 濃紫 透明度 80%
- 位置: 画面左端からはみ出す形で背景レイヤーに固定描画

### 自キャラ（プレイヤーアバター）

- 外円半径: **14.0 px**、色: `Color(0.26, 0.21, 0.28)`
- 内円半径: 7.7 px（外円の 55%）、色: 背景色（ドーナツ状）

## 2. 入力・操作

| 操作 | 効果 |
|------|------|
| マウス移動 | 自キャラターゲット位置をリアルタイム更新 |
| マウスクリック | 最近傍ドットの確認ポップアップ表示 |
| 左スティック / 十字キー | 自キャラ移動（速度 600 px/s、デッドゾーン 0.1） |
| A ボタン / Enter | 決定（最近傍のステージをプレイ） |
| B ボタン | キャンセル（ポップアップを閉じる） |
| L ショルダー | BGM 前曲へ |
| R ショルダー | BGM 次曲へ |
| ESC | タイトル戻り確認ポップアップ表示 |

### 自キャラ移動の補間

- マウス追跡: `lerp(current, target, 10.0 × delta)` — 係数 `_CHAR_LERP = 10.0`
- パッド直接移動: `pos += dir.normalized() × 600.0 × delta`（即座、クランプあり）

## 3. ステージドットのインタラクション

### 近接判定（吹き出し表示）

- 閾値: **140.0 px**（`_PROX_DIST`）
- 対象: UNLOCKED / CLEARED ドット
- 最近傍1つを `_nearest` として管理

### 吹き出し（バブル）

| 寸法 | 値 |
|------|----|
| 幅 | 225.0 px |
| 高さ | 300.0 px |
| 外枠幅 | 4.5 px |
| 左縦ストライプ幅 | 22.5 px |

**エリア構成（上から）:**

| エリア | 高さ | 内容 |
|--------|------|------|
| ヘッダ | 78.0 px | `#N` ステージ番号（39pt）＋ステージ名（20pt、未プレイは `???`） |
| 図形 | 117.0 px | ミニ図形プレビュー（プレイ済みのみ表示） |
| BEST 行 × 2 | 各 52.5 px | BEST TIME / BEST MOVES |

- ドロップシャドウ: offset (12.5, 12.5)、`Color(0.26, 0.21, 0.28, 0.30)`
- ドット位置へのしっぽ（三角）付き
- 表示位置: ドット右上（画面端でクランプ）

### 確認ポップアップ（ステージ選択）

- 背景オーバーレイ: `Color(0.26, 0.21, 0.28, 0.50)`
- ダイアログ寸法: 700 × 250 px（画面中央、バブルの直下）
- テキスト: 「このステージをプレイしますか？」（42pt、赤）
- ボタン: **[はい]**（左）/ **[いいえ]**（右）— 220 × 64 px
- ホバー: 四隅にサイン波ウェーブ＋シャドウ

**[はい] 時の処理:**
1. `StageSelectManager.pending_stage_id` にステージ ID をセット
2. `TransitionManager.play_triangle()` で三角ワイプ
3. `res://scenes/game.tscn` へシーン遷移

## 4. ステージ解放ロジック

### 初期状態

- ステージ 0 のみ `UNLOCKED`、他は全 `LOCKED`

### クリア時の解放

クリアしたステージを `CLEARED` にし、上下左右の隣接セルを `UNLOCKED`（LOCKED のもののみ）。

```
+---+---+---+
    | ↑ |
+---+---+---+
| ← | X | → |    X をクリア → 4 方向を解放
+---+---+---+
    | ↓ |
+---+---+---+
```

グリッド端では境界チェックを行い、範囲外には解放しない。

### 永続化

| 項目 | 値 |
|------|----|
| 保存先 | `user://stage_select_state.json` |
| タイミング | `mark_cleared()` / `update_best()` 呼び出し時に即時保存 |

**JSON 構造:**
```json
{
  "0": 2,
  "1": 1,
  "tutorial_shown": true,
  "best_times": { "0": 12.45 },
  "best_moves": { "0": 45 }
}
```
（state 値: 0=LOCKED, 1=UNLOCKED, 2=CLEARED）

## 5. BGM 切り替え UI

### 表示

- 位置: 右下（anchor right/bottom、マージン −20 / −14 px）
- 形式: `◀[L] ♪ [曲名] ♪ [R]▶`
- フォント: Mplus2-Medium.otf、20pt、`Color(0.5, 0.3, 0.3)`

### BGM 曲一覧（5 曲固定、循環）

`BGM_01-05` / `BGM_01-06` / `BGM_01-08` / `BGM_02-03` / `BGM_02-09`

### テキスト演出

| フェーズ | 時間 | 内容 |
|---------|------|------|
| タイプライター | 1.0 s | 1 文字ずつ表示 |
| 保持 | 5.0 s | 全文字表示のまま |
| 消去 | 2.0 s | 1 文字ずつ消える + CPUParticles2D 散布 |

### 無効化条件

- ステージ確認ポップアップ表示中
- ESC ポップアップ表示中

## 6. ESC ポップアップ（タイトル戻り確認）

- テキスト: 「タイトル画面へ戻りますか？」（42pt、赤）
- ボタン: **[はい]** / **[いいえ]**（ステージ確認ポップアップと同仕様）

**[はい] 時の処理:**
1. `BGMManager.stop()`
2. `TransitionManager.play_diagonal()` で対角ワイプ
3. `res://scenes/game.tscn` へシーン遷移（`pending_stage_id` 未設定 → `logo` state から再起動）

## 8. StageSelectManager 公開 API

```gdscript
# 状態照会
get_state(stage_id) -> int          # LOCKED=0 / UNLOCKED=1 / CLEARED=2
get_stage_name(stage_id) -> String
get_best_time(stage_id) -> float    # -1.0 = 未記録
get_best_move_count(stage_id) -> int  # -1 = 未記録
get_connections() -> Array          # [[a,b], ...] 隣接ペア一覧

# 更新
mark_cleared(stage_id) -> void      # CLEARED + 隣接 UNLOCKED + 保存
update_best(stage_id, time, moves) -> Dictionary  # {time: bool, moves: bool}
reset_all() -> void

# 公開変数
pending_stage_id: int       # ゲーム開始時のステージ ID
tutorial_shown: bool        # 永続化
tutorial_return_to: String  # セッション内のみ（"stage1" or "config"）
```

## 9. デバッグ機能（`OS.is_debug_build()` 時のみ）

### ゾウドット

- 位置: `Vector2(40, 80)`、半径 16 px、色: `Color(0.15, 0.10, 0.20)`
- クリックで zou.json ステージを `play_triangle()` で起動
- `_source_file == "zou.json"` で検索して index を動的取得

### SE 選択パネル

- 位置: (310, 12)（左上付近）
- 2 列（in / out）、列幅 108 px、列間隔 16 px
- クリックで SE を試聴再生
- `DebugSFXConfig.in_count / out_count` が 0 の場合は非表示

10. SE 選択パネル（デバッグ）
