# KATA-DRAW インク色（#433647）統一仕様

> **作成日**: 2026-07-05  
> **ステータス**: 仕様定義（未実装）  
> **関連調査**: KATA ポイント色の不統一に関するコード走査（2026-07-05）  
> **出典**: `scripts/ui_renderer.gd`、`scripts/title_intro_animation.gd`、`scripts/TransitionManager.gd`、`scripts/stage_renderer.gd`、`scenes/stage_select.gd`

---

## 1. 目的

ゲーム内の **黒に近い描画色** を、単一のブランドカラー **`#433647`** に統一する。  
頂点・辺・自キャラ・UI 枠／文字／影など、プレイヤーが「濃い紫＝KATA の色」と認識する要素の色味を揃え、 `#423647`（`Color(0.26, 0.21, 0.28)`）や純黒との混在を解消する。

---

## 2. 統一先カラー

| 項目 | 値 |
|------|-----|
| **HEX** | `#433647` |
| **Godot 記法（推奨）** | `Color("#433647")` |
| **8bit RGB** | R=67, G=54, B=71 |
| **float RGB** | 約 `(0.2627, 0.2118, 0.2784)` |

### 2.1 共通定数（実装方針）

実装時は **1 箇所の定数** を正とし、各所の直書き・近似 float を置き換える。

| 候補 | 配置案 | 備考 |
|------|--------|------|
| `INK_COLOR` | `Resources/game_config.gd` または `scripts/ui_renderer.gd` 先頭 | 新規名前。UI・KATA 双方から参照 |
| 既存 `POINT_COLOR` / `LINE_COLOR` | `scripts/ui_renderer.gd` | 既に `#433647`。他ファイルから参照する場合は static アクセスまたは GameConfig へ昇格 |

**本仕様書では統一先を `#433647` と呼称し、実装時の定数名は `INK_COLOR` を推奨する**（`POINT_COLOR` は KATA 頂点文脈に限定された名称のため）。

### 2.2 アルファ（透明度）の扱い

- **RGB は常に `#433647` の R/G/B を使用する。**
- 既存コードが `Color(0.26, 0.21, 0.28, 0.50)` のように **alpha 付き** で指定している場合、**alpha 値は変更しない**（例: `Color("#433647").lightened(0)` ではなく `Color(INK_COLOR.r, INK_COLOR.g, INK_COLOR.b, 0.50)`）。
- 演出用 lerp の **終端色** が黒の場合は、終端を `#433647` に変更する（開始色・中間補間は別途 [§5.3](#53-演出上の-lerp)）。

## 10. リスクと注意

1. **自キャラのコントラスト**: 中心を `#433647` にすると、従来より明るく見える。背景 `#FFF0E3` 上での視認性を実機確認する。
2. **吸着頂点の識別性**: 黒ディスクから `#433647` にすると、未吸着頂点と **色で区別しにくくなる**。必要なら半径・エフェクトのみで区別する（本仕様では色統一を優先）。
3. **影の alpha**: RGB だけ変えても、影色が本体と同系になるため、**影の見え方が弱くなる**可能性がある。実装後に UI ボタンを重点確認。
4. **grep 漏れ**: `0.2627, 0.2118, 0.2784` など float 直書きが残る場合がある。実装時は複数パターンで検索する。
