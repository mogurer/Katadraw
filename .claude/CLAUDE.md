# KATADRAW プロジェクト規約 (Claude Code 用)

このファイルは `.claude/CLAUDE.md` としてリポジトリ直下の `.claude/` フォルダに配置してください。
Claude Code はセッション開始時にこの内容を必ず読み込み、遵守すること。

## 1. 応答言語

- **すべての応答・コメント・コミットメッセージは日本語で書くこと。**
- 英語での応答は不可。もし英語で返ってきた場合は再実行を促す。

## 2. ブランチ運用

- 作業ブランチは常に **`main`**。`pin` や `old_main` など他のブランチを誤って使わないこと。
- 作業開始前に必ず `git branch --show-current` 等で現在のブランチを確認し、`main` であることをユーザーに報告してから作業に入ること。
- ブランチが `main` 以外だった場合は、作業を始めず先にユーザーに確認する。

## 3. 修正前の検証必須ルール

- **いかなる修正も、実施前に必ず現状のコードを提示し、根本原因を説明してから着手すること。**
- 思い込みや推測だけでコードを書き換えない。該当箇所を実際に読んでから判断する。
- 修正内容が複数ファイルにまたがる場合は、変更予定の一覧(ファイル名・変更概要)を先に提示し、ユーザーの了承を得てから実施する。

## 4. スコープ厳守

- 依頼された内容以外のファイルには手を加えない。
- 「ついでに直す」「ついでにリファクタリングする」は禁止。気づいた点があれば提案として報告するに留める。
- 1度の作業では1つの不具合・1つの機能に集中する。複数の依頼がある場合は独立性の高いものから順に1つずつ対応する。

## 5. 命名規則・技術的な決まりごと

- BGMファイル: `[name]_0000.ogg` (イントロ), `_0010.ogg`, `_0020.ogg`... (モチーフ) の連番形式。
- 音声アセットは `res://assets/sounds/` 配下に配置。
- 設定値の永続化は Godot `ConfigFile` (`user://config.cfg`) を使用。
- ローカライズ文言は `Resources/Translation/Translation.csv` を参照し、キー命名の一貫性を保つこと。
- マルチモニタ関連の処理では `get_window().current_screen` を使用し、画面インデックスをハードコードしない(`0`固定は不可)。
- クロスフェード等の音量制御は `sin`/`cos` による等パワーカーブを用い、線形dB補間は使わない。

## 6. ビルド・エクスポート

- Windows向けエクスポート時、`res://Resources/Translation/Translation.csv` を含む非スクリプト系リソースはエクスポートフィルタ (`*.csv` 等) に明示的に含めること。抜けると実行時エラーになる。

## 7. 完了報告

- 作業完了時は、変更したファイル一覧と変更内容の要約を日本語で報告する。
- 動作確認手順(どう確認すればよいか)を必ず添える。
